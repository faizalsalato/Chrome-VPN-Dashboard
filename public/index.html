Nova Instância

O CloakBrowser tem os patches de fingerprint no próprio binário. A tela abre pelo cliente web do KasmVNC, no mesmo endereço do subdomínio.

As chaves gerem-se no menu Chaves CloakBrowser.

As credenciais do provedor devem estar salvas em "Credenciais VPN".

Só é possível escolher um proxy já cadastrado. Para adicionar, editar ou testar proxies, use o menu Proxies.

🗝️ Chaves CloakBrowser

No modo grátis o CloakBrowser aceita uma sessão em paralelo; cada chave acrescenta sessões às instâncias que a usam. A chave nunca é exibida de volta (só as pontas).

Adicionar proxy

Cole uma lista (um por linha). Formatos aceitos: host:porta:usuario:senha, usuario:senha@host:porta ou host:porta. Linhas com # são ignoradas e proxies repetidos não são duplicados.
